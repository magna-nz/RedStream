# RedStream

Production-ready Redis Streams client for .NET — hosted consumers, PEL recovery, dead-letter queue, OpenTelemetry, on top of [StackExchange.Redis](https://github.com/StackExchange/StackExchange.Redis).

> 🚧 **v1 in development.** Full specification lives in [`SPEC.md`](SPEC.md). This README will be expanded with install instructions, a quickstart, and configuration reference as the package takes shape.
